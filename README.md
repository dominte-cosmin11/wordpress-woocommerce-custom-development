# WordPress & WooCommerce Custom Development

A portfolio collection of custom WordPress and WooCommerce functionality implemented with PHP, JavaScript, HTML and CSS.

## Included examples

- **WhatsApp product button** — shortcode that creates a WhatsApp message containing the current product name, SKU and URL.
- **Product brands taxonomy** — custom hierarchical taxonomy and a shortcode for displaying brand cards.
- **Stock sorting** — WooCommerce catalog sorting that places in-stock products first.
- **Shipping rules** — example rules for hiding free shipping and filtering shipping methods when a special shipping class is present.
- **Product search enhancements** — examples of extending product search and FiboSearch indexing/scoring.

## Requirements

- WordPress
- WooCommerce (for WooCommerce-specific examples)
- FiboSearch (only for the optional FiboSearch integration in `product-search/`)

## Installation

Each PHP file is a standalone example. Review the configuration comments, then add the relevant code to a small custom plugin or a child theme. Do not paste all files blindly into a production website.

## Notes

These examples are portfolio demonstrations based on practical WordPress/WooCommerce customization work. They are not presented as a complete standalone e-commerce application. Test on a staging site before production use.

## Technologies

PHP · WordPress Hooks & Shortcodes · WooCommerce APIs · JavaScript · CSS
